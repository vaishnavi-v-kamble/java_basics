**Java Basic Programs – Hello World and Arithmetic Operations**

This repository contains basic Java programs to practice fundamental programming concepts, including printing output and performing arithmetic operations using variables.

**Programs Included:**
- Print Hello World
- Create two variables and print their addition
- Calculate the difference between two variables
- Perform multiplication
- Perform division
- Calculate the modulus (remainder)

**Technologies Used:** Java

**Purpose:** To build a strong foundation in Java programming and understand basic arithmetic operators and output statements.
